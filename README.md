# CS19300-Final-Project
NBA Basketball Trivia

Project Goal:
I am going to build a java program that quizzes the user on basic NBA questions. It will give you questions like 'who scored more points in their career, LeBron James or Michael Jordan?' It will track your score over time and give you a score based on your answers.

MVP Scope:
* Basic question system
* Score tracking system
* Sourcing data 

Future Plans:
* Score History
* Advanced Questions

Tech Stack:
* Program language: Java
* Data storage: Comma-separated data files
* Data source: TBD, search for internet archives (Maybe basketball-reference.com)
* Libraries: Java CSV parser
